# COACH Project Page


This is the project page for the COACH paper, built with React and Vite. It is designed to be deployed as a static site on GitHub Pages, showcasing the paper, code, and demo information in a modern web interface.


## Deployment Instructions (GitHub Pages)

To deploy this project as a static site on GitHub Pages:

1. **Install dependencies:**
	```sh
	npm install
	```

2. **Build the project:**
	```sh
	npm run build
	```

3. **Deploy to GitHub Pages:**
	```sh
	npm run deploy
	```

This will publish the contents of the `dist` folder to the `gh-pages` branch of your repository, making the site available at `https://<your-github-username>.github.io/<your-repo-name>/`.

## Local Development

1. **Install dependencies:**
	```sh
	npm install
	```

2. **Build for production:**
	```sh
	npm run build
	```

3. **Preview the build locally:**
	```sh
	npm run preview
	```

For development, use:
```sh
npm run dev
```
